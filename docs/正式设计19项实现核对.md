## 仍需在目标环境验证的内容

这不是 19 项代码缺口，而是 Kind 无法替代的现场验证：

1. 当前 Kind 已部署 Prometheus 并完成 9 个 Worker 指标联调；联通现场仍需按真实指标名和 Node Label 校准 PromQL；
2. Kind 使用模拟 LLDP 邻接，物理集群需要验证真实网卡选择、`0x88CC` 报文、交换机命名与 NET_RAW 权限；
3. Demo 使用 Kubernetes v1.35.x、Volcano v1.15.0，接入目标集群前要按其实际版本重新做 API/二进制兼容性构建。
