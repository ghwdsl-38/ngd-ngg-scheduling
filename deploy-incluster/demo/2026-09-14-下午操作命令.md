## 6. 修复 master3 的 kubelet clusterDomain

用途：修复 master3 新建 Pod 的 Kubernetes Service 搜索域。今天发现配置中 `paas-hl-tstmix7` 重复了一次。

先检查配置：

**master3 Bash：**

```bash
systemctl is-active kubelet
grep -nE '^cluster(DNS|Domain):' /root/bink8s/cfg/kubelet.config
```

修复前：

```text
clusterDNS: [240.5.0.10]
clusterDomain: paas-hl-tstmix7.paas-hl-tstmix7.test.cucloud.unicom.cn
```

备份并精确替换：

```bash
test -e /root/bink8s/cfg/kubelet.config.bak-codex-20260914 || \
  cp -a /root/bink8s/cfg/kubelet.config /root/bink8s/cfg/kubelet.config.bak-codex-20260914

grep -q 'clusterDomain: paas-hl-tstmix7.paas-hl-tstmix7.test.cucloud.unicom.cn' /root/bink8s/cfg/kubelet.config && \
  sed -i 's#paas-hl-tstmix7.paas-hl-tstmix7.test.cucloud.unicom.cn#paas-hl-tstmix7.test.cucloud.unicom.cn#' /root/bink8s/cfg/kubelet.config

grep -nE '^cluster(DNS|Domain):' /root/bink8s/cfg/kubelet.config
```

使配置生效：

```bash
systemctl restart kubelet
systemctl is-active kubelet
kubectl get node hl-tstmix7-paasmaster3
```

重建 PRC 和 Algorithm Pod，使它们重新生成 `/etc/resolv.conf`：

```bash
kubectl rollout restart deployment/platform-resource-controller deployment/ngd-ngg-algorithm -n welkin-system
kubectl rollout status deployment/platform-resource-controller -n welkin-system --timeout=180s
kubectl rollout status deployment/ngd-ngg-algorithm -n welkin-system --timeout=180s
```

验证新搜索域及完整 Service FQDN：

```bash

kubectl exec -n welkin-system deployment/ngd-ngg-algorithm -- \
```

## 10. 演示结束后清理 NGD/NGG

用途：停止 PRC 每 15 秒刷新该需求。只删除 NGG 时，PRC 会根据仍存在的 NGD 再次创建它，因此应删除 NGD。

**master3 Bash：**

```bash
kubectl delete ngd go-test-demand --ignore-not-found=true --wait=true
kubectl get ngd,ngg
```

NGG 具有指向 NGD 的 `ownerReference`，会随 NGD 自动删除。

