## 测试一：Kubernetes 资源量纲

使用 `01-single-best.yaml`：

- NGD 输入：CPU `1`、内存 `1Gi`。
- NGD 结果：`Fulfilled`，选择 `hl-tstmix7-paasmaster1`。
- NGG 节点资源：CPU `101680m`、内存 `458090Mi`。
- NGG 汇总资源：CPU `101680m`、内存 `458090Mi`。

结果表明 Algorithm 可以解析 Kubernetes Quantity，PRC 在 NGG 中使用 Kubernetes 原生 CPU 和内存量纲，不再输出没有单位的字节整数。

## 测试二：失败根因

使用 `09-quota-too-small.yaml`：

- 最小资源：CPU `1`、内存 `1Gi`。
- Quota：CPU `80`、内存 `400Gi`。
- NGD 结果：`Failed`，没有生成 NGG。
- `status.message`：

```text
QUOTA_PREVENTS_MINIMUM: 3 nodes matched, but no node group can satisfy minResources within quota cpu=80000m,memory=409600Mi
```

结果表明失败状态能显示 quota 根因、匹配节点数和标准化后的资源上限，不再笼统显示为拓扑不满足。

## 清理结果

测试结束后已删除 `test-ngd-01-single-best` 和 `test-ngd-09-quota-too-small`。按测试标签查询 NGD/NGG 返回 `No resources found`。
